01 — whoami 卡片:脏块复现 vs 修复 移动鼠标感受修复版的摆动参数(±6.5° · lerp 0.09 · 视差 6px)

现状 · 透底 + 毛玻璃压噪点 灰斑
sean@agent ~ python
# whoami.py
class SeanYu(Engineer):
role = "Agent · RAG/LLM"
stack = ["Python", "FastAPI", "Docker"]
focus = "hybrid retrieval + rerank"
pattern = ["ReAct", "Plan-Execute"]
def ship(self, idea):
return evaluate(idea) > 0.9

成因:background: rgba(255,255,255,.045) 几乎全透,backdrop-filter: blur(14px) 把身后 .hero-grain 噪点纹理糊化成明暗不均的灰斑。

修复 · 近实心基底 + 放大 + 强摆动 Fixed
sean@agent ~ python
# whoami.py
class SeanYu(Engineer):
role = "Agent · RAG/LLM"
stack = ["Python", "FastAPI", "Docker"]
focus = "hybrid retrieval + rerank"
pattern = ["ReAct", "Plan-Execute"]
def ship(self, idea):
return evaluate(idea) > 0.9

修复:linear-gradient(rgba(18,18,18,.94),rgba(11,11,11,.94)) 基底 + inset 0 1px 0 rgba(255,255,255,.06) 顶部高光;字号 13→14.5px,内边距 24/26→30/34px,圆角 18→20px。
