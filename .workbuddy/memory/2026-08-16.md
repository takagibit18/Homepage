## Vercel 部署修复（styles.css / script.js 404）

- **根因**：`vercel.json` 中 `builds: [{"src":"index.html","use":"@vercel/static"}]` 仅把 index.html 作为构建入口，导致 styles.css、script.js 未被部署，线上 404。
- **关键发现**：Vercel 生产分支是 `main`（非 hero-variant-b）。线上 HTML 与 hero-variant-b 的 index.html 逐字节一致，是因为 PR #3 已将 hero-variant-b 合并入 main（bb32b2c）。
- **修复**：删除 `builds` 块，保留极简 `{"$schema":...,"framework":null}`。纯静态站零配置即可部署。
- **提交**：main 分支 `06e7613`，推送后 Vercel 自动部署生效。
- **验证**：`/`、`/styles.css`、`/script.js` 均返回 200，CSS/JS 内容与本地逐字节一致（diff IDENTICAL）。
- **教训**：`builds` 配置会缩小部署文件集，纯静态站不应加；排查 Vercel 问题时先确认生产分支（看 `Last-Modified` 时间戳与各分支 commit 时间对应关系）。
